# Assistant capabilities

The assistant answers website help questions with source links and can provide a selected month's personal expense summary for the owner of an active individual workspace. When Private document mode is enabled, it can answer questions about one selected, accessible PDF or text document after the uploader consents to indexing. It cannot write records, access unauthorized documents or accounts, retrieve bank balances, or provide live society, festival or kirana totals. Without AI configuration, it displays matching help sections and can return excerpts from existing ready document indexes. Ask each question with enough detail; displayed chat history is not sent to the model.
